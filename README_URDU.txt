صوفیہ جینی تبورڈا ویب سائٹ — پانچ Paid Folders کی اپ ڈیٹ
=====================================================

اس پیکج میں چار نئے Customer Pages ہیں: Photo Gallery، Gifts & Services، Long Package System اور WhatsApp Premium۔ ان کے ساتھ مشترکہ CSS/JavaScript اور موجودہ Code.gs کے لیے Patch بھی ہے۔ Premium Videos کا موجودہ صفحہ، Home Page اور admin.html تبدیل نہیں کیے گئے۔

اہم: یہ فائلیں تیار ہیں، لیکن ابھی GitHub پر اپ لوڈ یا Google Apps Script میں Deploy نہیں کی گئیں۔ Live Website پر تبدیلی آپ کے GitHub Repository میں فائلیں اپ لوڈ کرنے اور Code.gs Patch لگا کر New Version Deploy کرنے کے بعد آئے گی۔

GitHub میں موجودہ Repository کے Root میں یہ چھ فائلیں اپ لوڈ کریں: photo-gallery.html، gifts-services.html، long-packages.html، whatsapp-premium.html، paid-folder.css، paid-folder.js۔ Home Page، premium-videos.html اور admin.html کو Replace نہ کریں۔

Code.gs_PATCH.txt مکمل Code.gs نہیں ہے۔ اسے پورا Code.gs سمجھ کر Ctrl+A سے Replace نہ کریں۔ اس میں دی گئی مخصوص تبدیلیاں موجودہ Code.gs میں لگانی ہیں۔ میں آپ کو یہ کام ایک ایک قدم کرکے سمجھا سکتا ہوں۔

قیمتیں: Premium Videos $40 (موجودہ لنک برقرار)، Photo Gallery $20، Gifts & Services $10، Long Package System $80، WhatsApp Premium $60۔ PayPal لنکس FOLDER_SETTINGS_URDU.txt میں درج ہیں۔

Admin Panel میں Subscription Folder Prices کے اندر چار نئے فولڈرز کی قیمت اور PayPal Link محفوظ کریں۔ WhatsApp Contact والے حصے میں اپنا نمبر country code کے ساتھ یا username محفوظ کریں۔ WhatsApp رابطہ کسٹمر کو صرف Approval کے بعد دکھایا جائے گا۔

کسٹمر PayPal ادائیگی کے بعد نام، Gmail، Transaction ID اور Screenshot جمع کرے گا۔ درخواست Admin Dashboard میں آئے گی۔ آپ PayPal میں Transaction چیک کرکے Approve کریں گے۔ Photo/Gifts/Long Package کے لیے کسٹمر کو اسی Gmail پر Drive Folder access ملے گا۔ WhatsApp Premium میں contact صرف Approval کے بعد ظاہر ہوگا۔

ان چار نئے فولڈرز کی ادائیگی موجودہ Backend میں Admin کی دستی تصدیق پر مبنی ہے۔ صرف PayPal بٹن دبانے یا Screenshot بھیجنے سے ادائیگی خودکار طور پر Verified نہیں ہوتی۔ ٹیسٹ کے دوران حقیقی ادائیگی نہ کریں۔
